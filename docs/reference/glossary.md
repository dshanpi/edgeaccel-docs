# 常用术语

按操作中遇到的名称查阅。命令、配置字段和错误码保留原文，便于与程序输出对应。

## 设备与软件

| 名称 | 含义 |
|---|---|
| 主机 / 卡端 | 主机运行 Linux 或 Windows、管理应用；卡端执行模型计算。两者内存分别统计。 |
| AXCL | 主机访问算力卡的驱动、运行库和开发接口。 |
| PAC | 卡端固件包，须与硬件、容量和 AXCL 版本配套。 |
| NPU | 用于神经网络计算的处理单元。 |
| CMM | 卡端供模型、输入输出和视频缓冲区使用的内存。可用容量不等于标称内存总量。 |
| provider / 执行后端 | Python 推理会话实际使用的计算后端。本卡使用 `AXCLRTExecutionProvider`。 |
| runtime / 运行时 | 加载模型、分配资源并执行推理的软件。 |
| revision / 提交号 | 仓库某次提交的固定标识，用于复现文件版本。 |
| SHA256 | 文件内容的校验值，用于检查下载与传输前后是否一致。 |

## 模型与输入输出

| 名称 | 含义 |
|---|---|
| shape / dtype | 张量的尺寸与数据类型，例如图片的高、宽、通道数及整数或浮点格式。 |
| tokenizer / 分词器 | 将文本转换为模型使用的 token 编号，并将输出编号还原成文本。 |
| token | 模型处理文本的单位，不固定对应一个汉字或英文单词。 |
| Embedding / 向量 | 用一组数值表示文本、图片或声音，可用于相似度比较与检索。 |
| KV Cache | 生成文本时保存上下文计算结果的缓存；上下文增长通常会增加其内存需求。 |
| INT4 / INT8、W4A16 | 量化或数值精度标记。W4A16 表示 4 位权重、16 位激活；不同量化包不能直接互换。 |
| letterbox / NMS | 前者在保留宽高比时缩放并补边；后者按分数和重叠程度筛选重复检测框。 |

## 性能指标

| 指标 | 阅读方法 |
|---|---|
| TTFT | 首 token 耗时。须区分程序内部计时与客户端实际等待时间。 |
| token/s | 每秒生成的 token 数，不等于每秒字符数。 |
| FPS | 每秒处理或输出的帧数。推理帧率、视频输出帧率可能不同。 |
| RTF | 处理时间 ÷ 音频时长。小于 1 表示处理速度快于播放速度。 |
| P50 / P95 | 分别有 50% / 95% 的测量值不超过该数值，常用于描述延迟分布。 |
| RSS | 进程实际占用的主机物理内存，与卡端 CMM 分开记录。 |

比较性能前，先核对[计时范围与检查方法](validation.md)。
