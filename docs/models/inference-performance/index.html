常见模型推理耗时参考

处理一张图片需要多久？大模型多久开始回复？本页整理爱芯元智官方公开的 AXCL 基准数据，帮助您在部署 AX8850 应用前估算模型的响应速度。

测试条件与适用范围​

数据来源于官方 AXCL NPU Benchmark。查阅时文档版本为 AXCL V3.16.0，工具链为 Pulsar2 5.1-patch1；视觉模型使用 axcl_run_model，本页选取 Batch 1 数据。

如何使用这些数据

以下为官方公开基准，供选型参考，不是本站 AX8850 8GB / 16GB 配置的实测结果或交付指标。原始基准页没有逐项注明卡型号、容量、量化精度、固件及运行程序版本，因此不能据此判断某个模型是否适合您的卡容量。部署配置与效果请同时查看模型目录。

官方以 IPS（每秒推理图片数）公布结果。下表的毫秒数按 1000 ÷ IPS 换算，保留两位小数；计时只覆盖设备端网络推理，不含主机前后处理和 PCIe 数据传输。

ResNet50224 × 2245761.74
YOLOv5s640 × 6403263.07
YOLOv8s640 × 6402484.03
YOLOv11n640 × 6408601.16
YOLOv11s640 × 6403053.28

来源：官方 Vision Model 表。

例如，YOLOv11s 的约 3.28 ms 表示模型执行耗时。摄像头采集、解码、缩放、检测框处理、叠图和编码还会增加应用耗时；不能将 305 IPS 直接当作视频输出帧率或多路视频的处理能力。六路 AI 视频推流需结合完整链路评估。

大语言模型：多久开始回复​

TTFT 是首 token 延迟，反映开始回复前的等待时间；生成速度表示后续文本的输出速率。token 是模型的分词单位，不等于一个汉字。

以下官方测试的提示词长度均为 128 tokens。

模型官方 TTFT（ms）官方生成速度（tokens/s）生成 128 tokens 用时（估算，s）
Qwen2.5-0.5B80403.20
Qwen2.5-1.5B150168.00
Qwen2.5-7B8004.826.67

来源：官方 LLM 表。最后一列按 128 ÷ 生成速度 计算，仅为生成阶段的量级估算，不包含首 token 等待、模型加载或请求排队，也不是完整请求的实测用时。实际生成速度会随上下文长度和配置变化。

模型官方图片编码耗时（ms）官方 TTFT（ms）官方生成速度（tokens/s）
Qwen3-VL-2B13532314.1
Qwen3-VL-4B1436787.0

语音识别：处理一段音频​

RTF（实时率）= 处理耗时 ÷ 音频时长，数值越小表示处理越快。下表选择三个语音识别模型，并以 10 秒音频举例。

Whisper-Tiny0.080.80
Whisper-Base0.111.10

来源：官方 Audio Model 表。估算值按 10 × RTF 计算，不代表流式识别的首字延迟；原表未给出音频样本和完整计时边界。

在自己的应用中确认性能​

选型时先确认模型效果与内存需求，再用实际业务输入测量响应时间。对比测试应固定主机、卡容量、模型与量化版本、AXCL / 固件、输入尺寸或长度，并记录是否包含加载、预处理和后处理。

  • 图片与视频：分别测模型耗时和端到端延迟；多路任务需同时运行后再统计。
  • 文本与多模态：分别记录首 token 延迟、生成速度、输出长度与峰值内存。
  • 语音：记录音频时长、处理耗时；需要实时字幕时另测首字延迟。

具体方法见测量性能与稳定性。准备部署时，返回按任务和容量选择模型或完整模型目录。
