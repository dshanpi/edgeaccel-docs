Qwen3-ASR-0.6B-AX650-C64-P448-CTX2047 部署指南

Qwen3-ASR-0.6B-AX650-C64-P448-CTX2047 用于语音识别。本页说明 M.2 算力卡的接入条件、部署步骤与结果检查方法。

已实测，效果仍需评估。查看部署效果。

准备运行环境​

本页效果展示使用 RK3576 + AX8850 16GB M.2；其他容量或平台需重新确认模型能否加载并正确运行。

在连接算力卡的 Linux 主机终端执行，RK3576 使用 ARM64 环境。首次部署先完成驱动与设备检查、安装 PyAXEngine和下载工具安装。已完成这些步骤可直接下载模型。

后文使用设备 0，运行前用 axcl-smi 确认设备可用。

下载模型与样例​

本页使用 AXERA-TECH/Qwen3-ASR-0.6B-AX650-C64-P448-CTX2047 的固定版本。下面下载本页选用的 45 个文件。

MODEL_DIR=~/edgeaccel/models/qwen3-asr-0-6b-ax650-c64-p448-ctx2047/db1e8640ea9e
mkdir -p "$MODEL_DIR"
~/edgeaccel/hf-env/bin/hf download AXERA-TECH/Qwen3-ASR-0.6B-AX650-C64-P448-CTX2047 \
  --include "*.axmodel" "README.md" "config.json" "model.embed_tokens.weight.bfloat16.bin" "post_config.json" "qwen3_tokenizer.txt" "silero_vad.onnx" "tokenizer/chat_template.json" "tokenizer/config.json" "tokenizer/configuration.json" "tokenizer/generation_config.json" "tokenizer/merges.txt" "tokenizer/preprocessor_config.json" "tokenizer/tokenizer_config.json" "tokenizer/vocab.json" \
  --revision db1e8640ea9e888aa0ac04f4edd410eee98ef817 \
  --local-dir "$MODEL_DIR"
cd "$MODEL_DIR"

保留当前终端中的 MODEL_DIR 变量，后续命令沿用此目录。下载受阻或需要离线复制时，见下载方式与文件校验。

准备语音识别依赖​

本例使用 RK3576 主机与 AX8850 16GB M.2 算力卡，将音频转换为文本。固定模型包包含音频前端、编码器、28 层语言模型、输出层及 BF16 词嵌入，下载约 1.37GB。另需预留 Python 依赖和结果空间。

在已安装 PyAXEngine 的主机虚拟环境执行：

source ~/edgeaccel/python-env/bin/activate
python -m pip install 'numpy==1.26.4' 'torch==2.5.1' \
  'transformers==4.51.3' 'tokenizers==0.21.4' 'ml-dtypes==0.5.3' \
  'soundfile==0.13.1' 'scipy==1.17.1'
python -c "import axengine; print(axengine.get_available_providers())"

输出须包含 AXCLRTExecutionProvider。本例使用 Python 3.12 与 PyAXEngine 0.1.3.rc3。

下载运行脚本，保存为 ~/edgeaccel/qwen_asr_card.py。下载文件校验清单，保存为 $MODEL_DIR/download-manifest.json。

运行音频识别​

将下方效果展示中的输入音频下载到 ~/edgeaccel/input.wav，在连接算力卡的 Linux 主机执行：

python ~/edgeaccel/qwen_asr_card.py \
  --model-dir "$MODEL_DIR" \
  --audio ~/edgeaccel/input.wav \
  --output ~/edgeaccel/results/qwen-asr-01

输出目录须尚不存在。程序先校验模型文件，再完成音频前处理、算力卡推理和文本解码，生成 deployment-result.json 与逐次调用记录 calls.jsonl。

检查识别文本​

python - <<'PY'
import json
from pathlib import Path
r = json.loads((Path.home() / 'edgeaccel/results/qwen-asr-01/deployment-result.json').read_text())
assert r['completed'] and r['terminatedWithEos']
assert len(r['sessions']) == 31
assert all(s['providerActual'] == 'AXCLRTExecutionProvider' for s in r['sessions'])
print(r['rawText'])
print('文件识别流程：', round(r['pipelineSeconds'], 3), 's')
PY

原始输出保留语言标记和结束标记，方便检查模型实际返回的内容。播放输入音频，逐句比较转写中的漏词、错词和标点。

替换输入音频​

将 --audio 改为自己的 WAV 或可由 SoundFile 解码的音频路径，并更换输出目录。脚本将多声道取均值、重采样到 16kHz；单次输入须大于 0 秒且不超过 30 秒，超长音频会明确报错。

本例运行离线文件识别，未接入仓库中的可选 VAD 模型。连续麦克风输入和长录音需要额外的分段与结果合并处理，不能直接套用本页的短音频结果。

流程计时包括前处理、模型加载、推理及运行后的文件校验，不含 Python 启动、依赖导入和运行前校验。逐次算力卡调用计时包含 PCIe 数据传输，不代表纯 NPU 计算时间，也不代表常驻服务吞吐。

音频掩码和提示模板参考 sherpa-onnx 的固定版本 AXCL 实现。本页始终使用上文 AXERA-TECH 官方仓库的 C64/P448/CTX2047 模型文件。
