## 准备原生程序

本例使用 RK3576 主机、AX8850 16GB M.2 算力卡和 AXCL 3.16.0。模型文件约 6.55GB，建议在模型目录所在文件系统预留至少 8GB 可用空间。程序依赖主机上的 OpenCV 4.6；视觉编码器、36 个文本层和输出层在算力卡执行。

下载[配套运行包](/examples/qwen3-vl4-20261001.tar.gz)，保存为 `~/edgeaccel/qwen3-vl4-20261001.tar.gz`。包内包含 ARM64 程序、校验工具、三张图片、八帧视频样本和固定源码。保留前文设置的 `MODEL_DIR`，在同一终端执行：

```bash
cd ~/edgeaccel
tar -xzf qwen3-vl4-20261001.tar.gz
chmod +x qwen3-vl4/bin/main
ldd qwen3-vl4/bin/main
python3 qwen3-vl4/verify_models.py --model-dir "$MODEL_DIR"
python3 qwen3-vl4/prepare.py \
  --model-dir "$MODEL_DIR" \
  --output "$HOME/edgeaccel/qwen3-vl4-run"
```

`ldd` 输出不应出现 `not found`，文件校验工具应输出 `Verified 41 model files`。准备工具创建独立运行目录；再次准备时使用新目录。

使用默认 384 × 384 视觉编码器、`top_k=1` 贪心选择，关闭嵌入文件内存映射。词嵌入在主机占用约 742MiB，运行前确认主机可用内存充足。本页结果仅覆盖 16GB 卡。

## 运行图片问答

```bash
bash ~/edgeaccel/qwen3-vl4-run/run_image.sh
```

本次模型放在外置存储，图片进程首次加载约 485 秒；后面的问答耗时不包含首次加载。换用其他存储时，加载时间会变化。等待出现 `prompt >>` 后，依次输入问题和图片路径：

```text
prompt >> Name the two animals in the foreground. Reply in one sentence.
image >> images/ssd_horse.jpg
```

可继续输入人数问题，并使用仓库自带的房间图片：

```text
prompt >> 画面中有几个人清晰可见？只回答人数。
image >> images/room.jpg
```

中文场景描述使用 `请用一句中文描述图片中的主要内容。`，图片路径可选 `images/room.jpg` 或 `images/ssd_car.jpg`。同一问题可重复输入，对照原始回答。在 `prompt >>` 输入 `q` 退出。

## 运行视频帧问答

退出图片程序后启动视频模式：

```bash
bash ~/edgeaccel/qwen3-vl4-run/run_video.sh
```

```text
prompt >> 请用两句中文描述这些视频帧中动物的动作。
video >> video
```

`video` 目录包含八张按文件名排序的 JPEG 帧。程序每两帧执行一组视觉编码，共四组，再生成回答。本例验证已抽取的帧序列，未覆盖 MP4 解码、抽帧或实时视频流。

## 替换输入并检查退出状态

图片模式可输入 Linux 主机上图片的绝对路径。先确认配套样图能够运行，再换成业务图片。视频帧应按时间顺序命名，本例只覆盖八帧输入。

在提示符输入 `q`，退出后执行：

```bash
echo $?
axcl-smi
```

退出码应为 `0`，设备列表中不应继续显示该推理进程。人数、对象、文字和动作需要对照输入核实，回答流畅不代表细节准确。
